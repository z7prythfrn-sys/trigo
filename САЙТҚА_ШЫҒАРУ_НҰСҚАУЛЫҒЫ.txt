TRIGO ШАЙҚАСЫ — ИНТЕРНЕТТЕГІ САЙТ (3 ноутбук, ортақ сілтеме)

Нәтиже: екі сілтеме шығады.
  1) Топтарға ортақ:    https://СЕНІҢ-САЙТЫҢ.onrender.com/team.html
  2) Мұғалімге (құпия): https://СЕНІҢ-САЙТЫҢ.onrender.com/?key=СЕНІҢ_КІЛТІҢ

ҚАДАМДАР (бәрі тегін)
1. github.com сайтында аккаунт ашыңыз → New repository (мысалы: trigo) → Public.
2. «uploading an existing file» арқылы осы папкадағы БАРЛЫҚ файлдарды жүктеңіз
   (server.py, index.html, team.html, hero_left.png, hero_right.png, intro.jpg, requirements.txt) → Commit.
3. render.com сайтында GitHub арқылы тіркеліңіз → New → Web Service → trigo репозиторийін таңдаңыз.
4. Баптаулар:
     Runtime:        Python 3
     Build Command:  pip install -r requirements.txt
     Start Command:  python3 server.py
     Instance Type:  Free
5. Environment Variables бөлімінде қосыңыз:
     TEACHER_KEY = өзіңіз ойлап тапқан құпия сөз (мысалы: mugalim2026)
6. Create Web Service басыңыз. 2–3 минуттан соң жоғарыда сайт мекенжайы шығады.

САБАҚ КҮНІ
- Сабаққа 5 минут қалғанда мұғалім сілтемесін ашып қойыңыз: тегін сервер ұйықтап қалады, алғашқы ашылуы ~1 минутқа дейін созылуы мүмкін.
- Мұғалім сілтемесін (?key=...) ТЕК өзіңіз пайдаланыңыз, оқушыларға бермеңіз.
- 3 ноутбукта team.html сілтемесін ашып, әр топ өз нөмірін таңдайды.
- Мұғалім «ШАЙҚАСТЫ БАСТАУ» басады.

ЕСКЕРТУ
- Мұғалім беті жабылса, ойын тоқтайды (ойынды мұғалімнің беті басқарады).
- Желі нашар болса, батырманы басу кідірісі байқалуы мүмкін.
- Оқушы team.html?team=2 сияқты басқа топтың сілтемесін білсе, сол топтың атынан бассып қоя алады.
